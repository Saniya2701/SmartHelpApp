# 🚀 Smart Local Help & Emergency Assistance App

> A smart Android-based safety and local services app that helps users find nearby help and send emergency alerts instantly.

---

## 🧠 Problem Statement

In many small cities and towns, people face serious difficulties in:

- 🚨 Quickly finding trusted local services (electricians, plumbers, mechanics)
- 🆘 Getting emergency help during accidents or health issues
- 📍 Sharing real-time location with family in danger
- ❌ No single unified safety + service platform exists

---

## 💡 Solution

This app solves these problems by providing:

- 📍 Nearby service discovery (Google Maps)
- 🆘 One-tap emergency SOS system
- 📡 Live location sharing with trusted contacts
- 📞 Quick emergency communication system
- 📶 Works even in low/no internet conditions (offline support)

---



## 🎯 Key Features

### 👤 1. User Module
- Firebase Authentication (Login / Signup)
- User profile (Name, phone, emergency contacts)

---

### 🆘 2. Emergency SOS System (MAIN FEATURE)
- One-click SOS button
- Sends:
  - 📍 Live location (Google Maps API)
  - 📩 Emergency SMS to contacts
  - 📞 Optional auto-call feature

---

### 📍 3. Nearby Help Finder
Find nearby professionals like:
- ⚡ Electrician
- 🚰 Plumber
- 🔧 Mechanic
- 🏥 Medical Help

Features:
- Map-based display
- Distance calculation
- Contact directly from app

---

### 📡 4. Live Location Sharing
- Real-time location sharing
- Useful for:
  - Late-night travel safety
  - Tracking family members
  - Emergency monitoring

---

### 🌐 5. Offline Mode (Advanced ⭐)
- Emergency contacts stored locally (SQLite)
- SMS works without internet
- Critical safety backup system

---

### ⭐ 6. Ratings & Reviews
- Users can rate service providers
- Builds trust and reliability

---

### 🔔 7. Notifications
- SOS alerts
- Emergency updates
- Service reminders

---
